## О русской сборке

Это полный русский форк LevelledMobs на базе версии `v4.5.3.2` (коммит `ab061bd4`).
Игровые сообщения, сообщения консоли и отладки, встроенные конфигурации, метаданные и комментарии исходного кода переведены в нейтрально-техническом стиле. В документации используется термин «уровневый моб».

- Русский форк: [BF-GO/LevelledMobs](https://github.com/BF-GO/LevelledMobs)
- Оригинальный проект: [ArcanePlugins/LevelledMobs](https://github.com/ArcanePlugins/LevelledMobs)
- Основная ветка русской сборки: `production`
- Чистое зеркало исходного проекта: `master`
- Воспроизводимые наборы патчей: `patches`

Авторство оригинального проекта и условия лицензии полностью сохранены. Русификация не изменяет внешнее API `levelledmobs-api`, команды, права доступа, ключи YAML, плейсхолдеры, PDC/NBT-ключи и технические имена Minecraft.

## Документация и установка

Подробности доступны на страницах оригинального проекта:

- [Страница на HangarMC](https://hangar.papermc.io/ArcanePlugins/LevelledMobs)
- [Страница на SpigotMC](https://www.spigotmc.org/resources/levelledmobs.74304/)
- [Инструкция по установке](https://arcaneplugins.gitbook.io/levelledmobs-the-ultimate-mob-levelling-solution/levelledmobs-v4.0/installation)
- [Ошибки и запуск LevelledMobs](https://arcaneplugins.gitbook.io/levelledmobs-the-ultimate-mob-levelling-solution/levelledmobs-v4.0/errors-and-running-lm)
- [Совместимость серверного ПО](https://arcaneplugins.gitbook.io/levelledmobs-the-ultimate-mob-levelling-solution/levelledmobs-v4.0/installation#are-you-running-a-compatible-server-software)

При первом запуске создаётся русский `messages.yml` версии 10. Существующий файл старой версии сохраняется в резервную копию и заменяется русским шаблоном; значения трёх управляющих флагов уведомлений переносятся автоматически.
